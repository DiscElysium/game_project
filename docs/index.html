01 / THE TELLS

AI 的心理，
藏在细节里。

每一轮，AI 根据手牌、当前叫牌和回合历史分析局势，生成具体的微表情描述。从目光到下颌，从手指到语气，反应随局势变化。

你得到的是一条线索，而非一句真假判决。

[ 目光 ]GAZE

看向你，
还是避开你？

「他的视线从骰盅滑向你，
又在与你对视前停住。」

一次迟疑，也可能让你改变叫牌。

[ 下颌 ]TENSION

笑容里，
有多少底气？

「嘴角短暂扬起，
下颌却比刚才绷得更紧。」

把反应放回叫牌历史里，再下判断。

[ 姿态 ]POSTURE

不动声色，
也是一种反应。

「他把身体向后靠，
手指却仍紧贴着骰盅边缘。」

脸上的平静，不会让底牌变得透明。

03 / THE RULEBOOK

同一颗骰子，
两种立场。

每人初始持有 4 颗普通骰子和 1 颗特殊骰子。
叫牌、质疑，再揭开骰盅。
你的底牌，不等于我的筹码。

01 / BID

叫牌

宣称全场至少有 X 个 Y 点。你可以握有底牌，也可以虚张声势。新的叫牌必须提高数量，或在数量相同时提高点数。

02 / CHALLENGE

质疑

不相信上一家的叫牌，就打开骰盅。实际有效数量达到叫牌数量，叫牌者胜；不足时，质疑者胜。

03 / THE TWIST

特殊骰

当叫牌者被质疑时，它符合叫牌点数的特殊骰子，每颗算 3 颗。其他人的特殊骰子不计数。同一颗骰子，立场决定价值。

你的底牌。
别人的盲区。

叫牌者的特殊骰子

1 = 3

点数匹配时，单颗计作三颗。

其他人的特殊骰子

1 = 0

本次质疑中，不参与计数。

叫牌之后 / 一次特殊行动

改变信息，
也改变局势。

[ X-RAY ]

透视 · 看见秘密

让一名对手的骰盅透明 3 秒，观察普通骰子的点数，为接下来的判断积累信息。

[ STEAL ]

窃取 · 夺走底牌

猜中一名对手的特殊骰子点数，将它收入自己的手牌。猜错则没有转移。
