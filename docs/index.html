01 / THE TELLS

AI 的心理，
藏在细节里。

每一轮，AI 根据手牌、当前叫牌和回合历史分析局势，生成具体的微表情描述。从目光到下颌，从手指到语气，反应随局势变化。

你得到的是一条线索，而非一句真假判决。

还是避开你？

又在与你对视前停住。」

一次迟疑，也可能让你改变叫牌。

[ 下颌 ]TENSION

笑容里，
有多少底气？

「嘴角短暂扬起，
下颌却比刚才绷得更紧。」

把反应放回叫牌历史里，再下判断。

[ 姿态 ]POSTURE

不动声色，
也是一种反应。

「他把身体向后靠，
手指却仍紧贴着骰盅边缘。」

脸上的平静，不会让底牌变得透明。

03 / THE RULEBOOK

同一颗骰子，
两种立场。

每人初始持有 4 颗普通骰子和 1 颗特殊骰子。
叫牌、质疑，再揭开骰盅。
你的底牌，不等于我的筹码。

01 / BID

叫牌

宣称全场至少有 X 个 Y 点。你可以握有底牌，也可以虚张声势。新的叫牌必须提高数量，或在数量相同时提高点数。

02 / CHALLENGE

质疑

不相信上一家的叫牌，就打开骰盅。实际有效数量达到叫牌数量，叫牌者胜；不足时，质疑者胜。

03 / THE TWIST

特殊骰

当叫牌者被质疑时，它符合叫牌点数的特殊骰子，每颗算 3 颗。其他人的特殊骰子不计数。同一颗骰子，立场决定价值。

你的底牌。
别人的盲区。

叫牌者的特殊骰子

1 = 3

点数匹配时，单颗计作三颗。

其他人的特殊骰子

1 = 0

本次质疑中，不参与计数。

叫牌之后 / 一次特殊行动

改变信息，
也改变局势。

[ X-RAY ]

透视 · 看见秘密

让一名对手的骰盅透明 3 秒，观察普通骰子的点数，为接下来的判断积累信息。

[ STEAL ]

窃取 · 夺走底牌

猜中一名对手的特殊骰子点数，将它收入自己的手牌。猜错则没有转移。

05 / THE DESIGNER’S NOTE

知其然，
也知其所以然。

我对 AI 的理解，来自原理，也来自大量实践。理解它的运行逻辑，让我更能判断它能做什么、适合做什么，以及怎样把它放进一个有效的系统。

概率建模 × 语言模型 × 交互设计

01 / 理解问题

“吹牛”的背后，也有数学。

这个 Game Jam 项目以大话骰为原型。我先用概率模型处理叫牌与质疑：看似依赖吹牛和表演的游戏，同样有理性的决策基础。测试时，这套策略一度让我连续多局难以取胜；但反复交手后，我也开始摸清它的习惯。

02 / 设计分工

把性格，变成影响决策的参数。

在混合原型中，我让大语言模型结合手牌与当前对局记录，输出风险偏好，再由数学策略调整质疑阈值、叫牌幅度与诈唬倾向。激进或冷静，因此成为策略中的实际差异；对白与微表情则把这些差异带到玩家面前。

03 / 验证与迭代

让技术判断，落成可以体验的设计。

我通过实际对局检验对手能否回应玩家的行为、表现与策略是否一致，并让模型输出可以被观察和调试。当前演示继续探索大模型决策与规则校验；更长期的玩家习惯建模，是我希望推进的方向。

混合原型 / 参数驱动的决策分工

  1. INPUT / 01

    读取对局

    手牌、叫牌与当前对局记录

  2. LANGUAGE MODEL / 02

    调整风险偏好

    大语言模型输出风险参数

  3. MATHEMATICAL STRATEGY / 03

    执行数学策略

    调整阈值与评分，
    执行叫牌或质疑。

迭代说明：上述参数调节对应混合原型。上方可玩版本采用大模型生成行动、游戏规则校验，并利用当前对局历史；长期玩家学习尚属探索方向。
